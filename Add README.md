# Static Verification of C++ Code

## Project Title
Monster Battle Game — Static Verification

## Objective
The objective of this lab task is to inspect C++ source code and identify programming defects without executing the program.

## Tools Used
- GitHub for source code and report management
- Manual source code inspection
- C++ programming language

## Review Activities
1. Review Checklist
2. Code Review Report
3. Identification of defects and their severity
4. Proposed solutions for the identified defects

## Project Files
- `game.cpp` — Original C++ source code
- `REVIEW_CHECKLIST.md` — Static verification checklist
- `CODE_REVIEW_REPORT.md` — Detailed defect report

## Verification Scope
Initialization, pointers, arrays and buffers, loops, arithmetic, control flow, function calls, and classes.

## Note
This report identifies potential defects through static source code inspection. The original source code is preserved for review.
